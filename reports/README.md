# Reports

Written conclusions, each traceable to database records (finding / decision /
observation / sim-run ids). Nothing here yet: no research findings exist.

| folder | contents |
|---|---|
| `trader_profiles/` | one model per trader, by funnel stage (discovery → exit), each claim typed stated / observed / inferred / validated |
| `cross_trader_analysis/` | what all traders share vs personal style, filled only with evidence |
| `hypotheses/` | hypotheses and their lineage (`hypotheses.csv` is generated) |
| `simulations/` | run reports; imitation (Objective A) and performance (Objective B) kept separate (`sim_runs.csv` is generated) |
| `failures/` | failed hypotheses and failed holdouts, written up rather than tuned away |
